# Project agent guidance
- Keep strict TypeScript; avoid `any`, suppressions and non-null assertions unless justified.
- Use SCSS Modules for component styles. Do not add Tailwind.
- Use Georgian for user-facing content. Do not invent competition rules, dates, fees or eligibility.
- Keep business functionality out until explicitly requested.
- Keep secrets out of source; use `.env.example` placeholders.
- Favor accessible controls, visible focus, labels and responsive layouts.
- Run build, typecheck, lint and tests before reporting completion.
